# AI Prompt Library

This repository is a collection of prompts, examples and test-oriented snippets intended to help software testers, developers and QA engineers use AI to generate test ideas, test data, automation scaffolding and exploratory test charters.

Contents
- English translations of the original prompts and examples are available in the `en/` directory (for example [en/01-ai-intro-file-upload-tests.md](en/01-ai-intro-file-upload-tests.md)).
- The repository now uses descriptive chapter file names (for example [01-intro-and-file-upload-tests.md](01-intro-and-file-upload-tests.md)) instead of the previous `rozdzialXX` naming.
- Original Polish source prompts are preserved as top-level Markdown files alongside their English translations in `en/`.

What you'll find
- Test ideas and threat models for web forms, booking systems and authorization APIs.
- Examples of data generation (JSON, XML, SQL) and sample seed scripts.
- Java snippets demonstrating testing patterns, Selenium page objects and simple test harnesses.
- Utilities and examples for integrating with AI models (placeholders for API keys).

How to use
1. Browse the English translations in the `en/` folder (e.g. [en/01-ai-intro-file-upload-tests.md](en/01-ai-intro-file-upload-tests.md)).
2. Read the corresponding Polish prompts and examples in the top-level descriptive Markdown files (e.g. [01-intro-and-file-upload-tests.md](01-intro-and-file-upload-tests.md)).
3. Copy and adapt prompts, code snippets or test cases into your projects or AI prompts for test-generation.
